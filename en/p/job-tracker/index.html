      About Job Tracker

      Personal job-application tracker with statistics: response rates and a hiring funnel.

      What it does

      • Create, view, edit and delete applications, with filters by company, type, modality, status and CV version.
      • KPIs, a cumulative funnel, applications per week and response rate by type or CV version.
      • Dashboard in plain HTML and JavaScript with Chart.js, no framework or build step.
      • The “No response” status cannot be set by hand: the system assigns it after 21 days without news.

      Key facts

      • REST API with FastAPI and automatic docs at /docs.
      • Runs with Docker Compose or, without Docker, on a local SQLite file.
      • Tests with pytest on an in-memory SQLite database.

      Technologies

      • Python
      • FastAPI
      • PostgreSQL
      • SQLAlchemy
      • Pydantic
      • Pandas
      • Docker
      • pytest

      Limits (stated plainly)

      It has no authentication yet, and the “No response” check runs at query time, not in the background. Planned next step: split companies, interviews, technical tests and CV versions.

      What this mock-up is

      A desktop program from another era that reproduces the app: add applications in one line, statuses, stalled ones, KPIs and charts, with the app's own logic (response rates, funnel, “No response” after 21 days).

      The data is sample data with made-up companies: the real app stores personal applications and they are not published. Changes you make here only live in this tab.

      Not included: the FastAPI API, the PostgreSQL database, the filters by modality and CV version, or full editing of every field. That is only in the repository.

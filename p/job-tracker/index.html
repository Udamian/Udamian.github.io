      Acerca de Job Tracker

      Seguimiento personal de candidaturas de empleo con estadísticas: tasas de respuesta y embudo de selección.

      Qué hace

      • Crear, ver, editar y borrar candidaturas, con filtros por empresa, tipo, modalidad, estado y versión del CV.
      • KPIs, embudo acumulado, candidaturas por semana y tasa de respuesta por tipo o por versión del CV.
      • Dashboard en HTML y JavaScript puros con Chart.js, sin framework ni paso de compilación.
      • El estado «Sin respuesta» no se puede poner a mano: el sistema lo asigna tras 21 días sin novedades.

      Datos clave

      • API REST con FastAPI y documentación automática en /docs.
      • Se levanta con Docker Compose o, sin Docker, con SQLite local.
      • Pruebas con pytest sobre una base SQLite en memoria.

      Tecnologías

      • Python
      • FastAPI
      • PostgreSQL
      • SQLAlchemy
      • Pydantic
      • Pandas
      • Docker
      • pytest

      Límites (dichos con claridad)

      Todavía no tiene autenticación y la comprobación de «Sin respuesta» se hace al consultar, no en segundo plano. Siguiente paso previsto: separar empresas, entrevistas, pruebas técnicas y versiones de CV.

      Qué es esta maqueta

      Un programa de escritorio de otra época que reproduce la app: añadir candidaturas en una línea, estados, estancados, KPIs y gráficos, con la misma lógica de la app (tasas de respuesta, embudo, «Sin respuesta» tras 21 días).

      Los datos son de ejemplo, con empresas inventadas: la app real guarda candidaturas personales y no se publican. Los cambios que hagas aquí solo viven en esta pestaña.

      No incluye: la API de FastAPI, la base de datos PostgreSQL, los filtros por modalidad y versión del CV ni la edición completa de cada campo. Eso solo está en el repositorio.

      Enlaces

      No hay demo en línea de la app original: necesita su API y una base de datos.
